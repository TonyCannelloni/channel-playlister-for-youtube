    Setup

    Credentials stay in this browser only. Nothing is sent to a server except YouTube, Google, and Discogs when you use those features.

    YouTube Data API key (required)

    Create a free key in Google Cloud Console. Enable YouTube Data API v3, then Credentials, Create API key. Restrict it to HTTP referrers and add https://tonycannelloni.github.io/* (or your Pages URL with /*).

    Google OAuth client ID (optional)

    For Save to YouTube. Web application type. Add your site URL under authorized JavaScript origins.

    Discogs token (optional)

    For genre lookup. Personal token from Discogs developers settings.
